# Trainings

Competitive programming and interview preparation. Mostly Python, some C++.

This is a practice repository, not a product — I keep it public because the habit matters more than any single solution here.

## What's inside

| Folder | What it is |
| --- | --- |
| `beecrowd/` | Beecrowd (formerly URI) problems, sorted by category |
| `codeforces/` | Codeforces contest problems |
| `leetcode/` | LeetCode, grouped by pattern rather than by number |
| `data-structures-and-algorithms/` | Implementations from scratch: lists, trees, graphs, sorting |
| `interview/` | Interview-style problems, with notes on approach and complexity |
| `selection-2024/` | ICPC-style selection contest, 2024 |
| `turing/` | Turing platform technical assessment problems |

## How I use it

For anything non-trivial I write a short comment at the top of the file with:

- the approach in one line
- time and space complexity
- what I got wrong on the first attempt, when it's worth remembering

The last one is the useful part. A solution I got right immediately teaches me
less than one where I picked the wrong data structure and had to back out.

## Notes

Solutions are mine and written for practice, so they favour clarity over
micro-optimisation unless the problem's constraints demanded otherwise.
